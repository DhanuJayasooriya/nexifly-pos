# Nexifly POS: Frontend

React 18 single-page app for Nexifly POS, built with [Vite](https://vite.dev). See the [main README](../README.md) for the full setup.

```bash
npm install
npm start        # dev server on http://localhost:3000
npm run build    # production build in ./build
```

In development, requests to `/api` are forwarded to the backend at `http://localhost:4000` (see `vite.config.js`).

**Main libraries:** React Router 7, Axios, Recharts (dashboard charts), react-hot-toast.
